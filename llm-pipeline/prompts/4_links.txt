# File format: every prompt starts with a line  ===== NAME =====  and runs until the next such line.
# <<name>> is a placeholder that the code fills in (the sentence, the candidate list, ...).
# Lines starting with # are comments and are never sent to Gemini.
#
#   1. PAIR_DETECTION (+ PAIR_DETECTION_MISSING for events still unlinked): which pairs are linked,
#      sentence by sentence (current sentence + previous sentence + the report date)
#   2. RELATION_STEP + RELATION: ...  - one YES/NO question per relation type, most specific first
#   3. RELATION_FALLBACK - single-choice relation for links that got NO everywhere (else SIMULTANEOUS)
#   4. CROSS_REPORT - links between two consecutive reports of the same patient
# The direction of every link is fixed by the code before typing: event -> temporal expression,
# otherwise the later mention -> the earlier mention.



# The 13 relation types. Inserted as <<relations>> in RELATION_FALLBACK and CROSS_REPORT.
===== TLINK_RELATIONS =====
RELATIONS (read as: SOURCE relation TARGET)

TLINK_before (BEFORE) – source occurs before target ("É de referir que o FLT3 foi positivo": positivo BEFORE referir).

TLINK_after (AFTER) – source occurs after target ("O aspirado medular mostrou 48% de blastos": mostrou AFTER aspirado medular).

TLINK_before_overlap (BEFORE_OVERLAP) – source starts before target and continues into it ("iniciou tratamento a
   2.4.23, sendo já seguido pelo médico": seguido BEFORE_OVERLAP 2.4.23).

TLINK_after_overlap (AFTER_OVERLAP) – source starts after target but within its timeframe ("febre, vómitos e mais
   recentemente cefaleias": cefaleias AFTER_OVERLAP vómitos; cefaleias SIMULTANEOUS recentemente).

TLINK_includes (INCLUDES) – source includes target ("Uma punção lombar mostrou envolvimento do SNC": envolvimento INCLUDES mostrou).

TLINK_is_included (IS_INCLUDED) – source is included in target ("tinha iniciado antibioterapia no dia anterior":
   iniciado IS_INCLUDED o dia anterior; "Por esse motivo fez um hemograma": fez IS_INCLUDED motivo).

TLINK_during (DURING) – source occurs during target ("Durante o exame físico, referiu dores intensas": dores
   intensas DURING exame físico).

TLINK_simultaneous (SIMULTANEOUS) – same time; also the DEFAULT when nothing allows a more specific relation
   ("hipersudorese e infeções de repetição": infeções de repetição SIMULTANEOUS hipersudorese).

TLINK_identity (IDENTITY) – the same eventuality: "quadro caracterizado por": caracterizado IDENTITY quadro;
   relative pronoun ("um hemograma que mostrou": que IDENTITY hemograma); "hemograma IDENTITY fez"; causatives
   ("A infeção causou aumento": causou IDENTITY infeção, aumento AFTER causou); light verbs ("deu entrada":
   entrada IDENTITY deu; "teve alta a 2.3.2017": alta IDENTITY teve, alta IS_INCLUDED 2.3.2017); reporting verbs
   referring to the same act ("disse ... Referiu ainda": referiu IDENTITY disse).

TLINK_begins (BEGINS) – source begins target ("dor abdominal desde abril de 2014": dor abdominal BEGINS abril de 2014).

TLINK_ends (ENDS) – source ends target ("Glasdegib termina a 5.6.2012": termina ENDS 5.6.2012).

TLINK_begun_by (BEGUN_BY) – source is begun by target ("Em janeiro de 2014, inicia queixas": queixas BEGUN_BY
   inicia, inicia BEGUN_BY janeiro de 2014).

TLINK_ended_by (ENDED_BY) – source is ended by target ("Em abril de 2013, terminou o tratamento": tratamento
   ENDED_BY terminou, terminou ENDED_BY abril de 2013).

===== PAIR_DETECTION =====
TASK (Link Structures › Temporal Links: pair detection). Find the pairs of entities of the CURRENT
sentence that must be connected by a temporal link (TLINK). Do NOT decide the relation type yet.
Entities are marked ⟦E# ...⟧ (events) and ⟦T# ...⟧ (temporal expressions); <<doctime_id>> is the DOCTIME (report
creation date, <<dct>>).

A TLINK connects two events, two temporal expressions, or an event and a temporal expression, whenever the text
allows ordering them in time: an event and the temporal expression that locates it; an event and the event it
depends on (argument of a reporting / aspectual / intensional verb, examination and its result, cause and
effect); coreferent mentions (relative pronoun and antecedent, light verb and its noun, "quadro caracterizado
por"); consecutive events of the narrative. Link every event of the current sentence to at least one entity.

RULES
- At least one entity of each pair belongs to the CURRENT sentence; the other may be in the current sentence, the
  previous sentence(s) or the DOCTIME.
- Only use IDs from the ENTITIES list.

<<current>>

<<entities>>

Return JSON: {"pairs": [{"source": "<entity ID>", "target": "<entity ID>"}, ...]}

# <<definition>> for TLINK_identity (step P3.1).
===== RELATION: IDENTITY =====
read the link as "SOURCE IDENTITY TARGET" (the direction is fixed): the two mentions are the SAME eventuality: "quadro caracterizado por" (caracterizado IDENTITY quadro); relative pronoun and antecedent ("um hemograma que mostrou": que IDENTITY hemograma); "fez um hemograma" (hemograma IDENTITY fez); causative verb and cause ("A infeção causou": causou IDENTITY infeção); light verbs ("deu entrada": entrada IDENTITY deu; "teve alta": alta IDENTITY teve); reporting verbs for the same act (referiu IDENTITY disse); repeated mentions.

# <<definition>> for TLINK_begins (step P3.2).
===== RELATION: BEGINS =====
read the link as "SOURCE BEGINS TARGET" (the direction is fixed): the source BEGINS the target / the target starts at the source ("dor abdominal desde abril de 2014": dor abdominal BEGINS abril de 2014; "internamento de abril a maio": internamento BEGINS abril).

# <<definition>> for TLINK_ends (step P3.3).
===== RELATION: ENDS =====
read the link as "SOURCE ENDS TARGET" (the direction is fixed): the source ENDS the target ("Glasdegib termina a 5.6.2012": termina ENDS 5.6.2012; "internamento de abril a maio de 2017": internamento ENDS maio de 2017).
