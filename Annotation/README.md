# Med2Story Temporal Annotation Scheme — Guidelines and Resources

## Overview

This folder contains the annotation guidelines and supporting resources for the **Med2Story Temporal Annotation Scheme**, developed for the temporal annotation of clinical narratives written in European Portuguese.

The resources include detailed annotation instructions, a visual overview of the scheme, a summary of cross-document annotation rules, and information on the distribution of medical report types across patients in the dataset.

## Folder Contents

| Resource | Description |
| --- | --- |
| **Med2Story Annotation Guidelines** | Detailed guidelines describing the annotation categories, criteria, and procedures used in the Med2Story Temporal Annotation Scheme. |
| **Med2Story Scheme** | Schematic overview of the annotation scheme and its structure. |
| **Cross Document Annotation** | Visual summary of the rules governing cross-document temporal annotation. |
| **Distribution of MR by patient** | Distribution of medical report types by patient in the dataset. |
